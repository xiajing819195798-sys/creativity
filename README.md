# 小学五、六年级创造性思维后测平台

在线地址：<https://xiajing819195798-sys.github.io/creativity/>

## 测评结构

- 2 道前后测锚题：数字故事 2983、拼车方案
- 4 道创造性思维平行任务：书面表达、社会问题解决、科学问题解决
- 2 道中文 AUT：纸杯、纸盒
- 共 8 题，建议用时 35–45 分钟

## 数据与评分

学生答案只保存在当前浏览器，不会由本网站自动上传。完成后可下载 CSV 和 JSON 备份，再按研究方案统一回收。CSV 会自动记录匿名编号、年级、班级代码、总用时、各题作答与各题用时；AUT 自动统计去重后的流畅性数量，并预留灵活性、独创性和适切性的人工评分列。

正式施测前请完成知情同意、预测试、评分员培训和数据回收演练。班级代码建议代表“学生归属班级”，教师轮转信息另建教师—班级—时段对应表，不要把姓名放进学生答题文件。

## 发布

仓库已配置 GitHub Pages 自动发布。若在线地址首次打开显示 404，请到仓库 **Settings → Pages → Build and deployment**，将 **Source** 设为 **GitHub Actions**，随后在 **Actions** 页重新运行发布流程。

## 使用说明

本工具不是正式 PISA 或 OECD 测验。部分任务依据 PISA 2022 创造性思维公开题的构念与情境进行中文简化或改编，改编内容由研究者负责，OECD 不对本工具背书。
